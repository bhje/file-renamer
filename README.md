## Features

* **Drag & Drop Support**
* **CSV Mapping**
* **Live Preview**
* **Resizable table**

## Built with // Dependencies

* **Python 3.x**
* **Tkinter** (GUI)
* **TkinterDnD2** (Drag and drop functionality)
* **Natsort** (For sorting)

## Installation // User tutorial

1. **Clone the repository** git clone https://github.com/bhje/file-renamer.git
2. **Install the dependencies** pip install tkinterdnd2 natsort
3. **Locate the project folder**
4. **Run the application**
5. **Select Input, CSV and Output**
6. **Choose a column from the dropdown-menu**
7. **Click "Run renamer" to start the process**
